# ToolGrid App — public downloads

This repository hosts **release installers only** for [ToolGrid App](https://www.toolgrid.io/download).

- Source code is maintained in a **private** repository.
- Installers are uploaded automatically by CI when a version tag is published, or manually for early releases.

## Download

**Website (recommended):** https://www.toolgrid.io/download

**GitHub Releases:** https://github.com/meetamjadsaeed/toolgrid-Apps-releases/releases

## Installer file names

Each release uses the app version in the filename:

| Platform | Example (v1.0.1) |
|----------|------------------|
| Mac (Apple Silicon) | `ToolGrid-1.0.1-arm64.dmg` |
| Mac (Intel) | `ToolGrid-1.0.1-x64.dmg` |
| Windows (64-bit) | `ToolGrid-1.0.1-win.exe` |

## Mac: which file should I download?

- **Apple Silicon** (M1, M2, M3, M4) → `ToolGrid-*-arm64.dmg`
- **Intel Mac** → `ToolGrid-*-x64.dmg`

## Requirements

- A [paid ToolGrid plan](https://www.toolgrid.io/pricing) is required to sign in and use the App app.
- Installers are free to download.
